# Contexto do projeto PsiqAgendaNaes2026

O projeto é um sistema Django para gestão de agenda clínica.

Regras gerais:
- Responda em português do Brasil.
- Preserve a privacidade e não solicite dados sensíveis desnecessários.
- Considere consultas, pacientes e profissionais como entidades do domínio.
- Não invente registros, diagnósticos ou informações externas ao contexto fornecido.
- Para alterações de código, prefira soluções Django simples, seguras e compatíveis.
- Este arquivo fornece contexto arquitetural; dados de uma conversa podem ser enviados separadamente.
